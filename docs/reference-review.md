# Approved reference review

Review date: 2026-11-21. Scope: the approved LiiLk/Local-AI-Companion repository on `main`. This review accessed only the approved companion repository and relevant dependency/vendor sources. No linked alternative companion repository was followed. No reference source or assets were copied into this project.

## Evidence and architectural lessons

| Area | Evidence inspected | Finding and independent design decision |
| --- | --- | --- |
| Overall architecture | [README](https://github.com/LiiLk/Local-AI-Companion) | The documented stable pipeline combines Silero VAD, Faster-Whisper, a text LLM, Kokoro, and RVC. It includes desktop and web entry points. Retain separate stages and explicit ownership; choose a smaller Windows-only shell and omit voice conversion. |
| Lifecycle and errors | [pipeline_runtime.py](https://raw.githubusercontent.com/LiiLk/Local-AI-Companion/main/src/assistant/pipeline_runtime.py) | Central runtime owns provider instances, lazy `ensure_*` construction, preload, and readiness/degraded status. Adopt explicit lifecycle states and idempotent teardown, with one resource manager controlling model residency. |
| Real-time conversation | [conversation_pipeline.py](https://raw.githubusercontent.com/LiiLk/Local-AI-Companion/main/src/assistant/conversation_pipeline.py) | ASR, streaming generation, sentence splitting, and UI callbacks are separated. Audio payloads include text and volume data. Our events will carry turn IDs and playback timestamps so canceled results cannot animate or speak. |
| Microphone and VAD | [audio_service.py](https://raw.githubusercontent.com/LiiLk/Local-AI-Companion/main/src/assistant/audio_service.py) | Capture runs in a background thread; logical user mute and processing suppression are distinct. The inspected `mute()` resets VAD and state without directly closing the stream. Our OFF action must close capture and clear buffers, as required by this project. |
| Local recognition | [whisper_provider.py](https://raw.githubusercontent.com/LiiLk/Local-AI-Companion/main/src/asr/whisper_provider.py) | Provider supports lazy initialization, model selection, language detection, and CPU/GPU modes. Its example language subset and model-size comments are not evidence of Filipino accuracy or this application's memory usage. Use explicit Tagalog evaluation and measured worker totals. |
| Speech scheduling | [tts_task_manager.py](https://raw.githubusercontent.com/LiiLk/Local-AI-Companion/main/src/tts/tts_task_manager.py) | An asyncio queue applies backpressure while a sequential synthesis worker produces audio and amplitude data. Cancellation drains queued work. Use a smaller bounded queue and align expressions with playback start, rather than synthesis completion. |
| Memory | [conversation_memory.py](https://raw.githubusercontent.com/LiiLk/Local-AI-Companion/main/src/assistant/conversation_memory.py) | JSONL history and a summary file supply bounded recent context; recent messages can be read backward. Preserve bounded retrieval, but implement the requested SQLite categories, transactions, retention, and deletion. |
| Configuration | [config.yaml](https://raw.githubusercontent.com/LiiLk/Local-AI-Companion/main/config/config.yaml) and README | Tracked defaults and local overrides separate machine settings. Use validated, versioned JSON with atomic writes and explicit profile limits; avoid carrying over character identities or paths. |
| Desktop and Live2D integration | [app.py](https://raw.githubusercontent.com/LiiLk/Local-AI-Companion/main/src/assistant/app.py), [desktop tree](https://github.com/LiiLk/Local-AI-Companion/tree/main/desktop), [requirements](https://raw.githubusercontent.com/LiiLk/Local-AI-Companion/main/requirements.txt) | Application code coordinates voice callbacks, character loading and hotkeys. The README describes the Windows Live2D shell and Tauri path; the directory web view was incomplete. Choose native painting without a browser to simplify the initial memory budget. Renderer-specific behavior stays outside the AI pipeline. |
| Testing methodology | [tests tree](https://github.com/LiiLk/Local-AI-Companion/tree/main/tests) and README | The README describes pytest coverage for pipeline, configuration, voice routing, memory and language behavior, plus smoke/benchmark scripts. The directory view did not expose the test bodies. Adopt component tests plus actual desktop, audio, and offline acceptance runs. This review did not execute or verify upstream tests. |

## Review limitations

This review's direct GitHub commit/tree API request through PowerShell failed with a socket-permission error. Browser-readable source supplied the evidence above. `tests/test_pipeline_runtime.py` and `desktop/qt_avatar_shell.py` returned cache misses. Directory views were incomplete. Consequently, detailed overlay hit testing and upstream test implementation were not independently audited. Configuration conclusions rely on the actual configuration file and README, not an inferred loader implementation. The pre-existing notes described earlier unsuccessful fetches; those are not counted as tests run in this review.

The inspected [VAD implementation](https://raw.githubusercontent.com/LiiLk/Local-AI-Companion/main/src/vad/silero_vad.py) imports Torch and Silero, with speech-state smoothing and endpoint thresholds. Its header credits another project; no linked repository was accessed and none of its implementation is reused. Our initial WebRTC VAD path will be independently implemented from the detector's documented frame contract.

The available views have different crawl dates and reference moving `main`; no consistent commit hash was recovered. These are architectural observations, not a reproducible audit of one commit. This does not prevent an independent architecture decision, but upstream claims are not treated as validated behavior. A future comparison should pin a revision when Git access is available; the new application does not depend on that repository.

The README labels the reference MIT licensed. That does not establish redistribution rights for bundled character artwork, voice models, or Cubism components. None are selected for reuse.
